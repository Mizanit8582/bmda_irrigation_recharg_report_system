# BMDA Irrigation Report System

A desktop-based irrigation report management system developed for managing daily irrigation data, charge collection reports, and analysis.

## Project Overview

BMDA Irrigation Report System helps users to enter, store, and view daily irrigation information from different zones and upazilas.

The system provides:
- Daily irrigation data entry
- Report searching
- Irrigation charge calculation
- Previous year charge comparison
- Database-based report management

## Features

✅ User Login System  
✅ Zone Based Access  
✅ Daily Report Entry  
✅ Upazila Wise Report Search  
✅ Irrigation Charge Calculation  
✅ Previous Year Charge Comparison  
✅ PostgreSQL Database Integration  
✅ Automatic Database Table Creation
